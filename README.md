# Maggie’s Plus

A responsive static storefront preview for Maggie’s Plus, a plus-size thrift shop in Nairobi. The site includes a looping hero video, a sample style catalogue, Instagram and WhatsApp links, shop location details, and M-Pesa reservation guidance. There is no checkout or payment integration.

## Preview locally

Open the index.html file in a browser, or serve this folder over HTTP:

    python -m http.server 4173

Then visit http://localhost:4173.

The fonts and catalogue photography load from Google Fonts and Unsplash, so those visual assets need an internet connection. The hero video and profile logo are stored locally in assets/.

- Reservations: via M-Pesa after the shop confirms the item and reservation steps

## Before launch

The product names, photos, and sample prices are illustrative preview content, not live inventory. Replace them with confirmed items, photos, sizes, and prices. Confirm any payment instructions with the shop before adding them to the website.
